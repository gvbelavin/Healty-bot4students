# Дневной план для студентов

Telegram-бот собирает один день: три приёма пищи, короткие активности и одну мини-тренировку. Основа — [BaymaxBro](https://github.com/xylonnnnnn/BaymaxBro). Поведение и структура приведены к спецификации MVP: локальный каталог, диалог диагностики и единый план. Внешняя языковая модель не используется.

## Запуск

Нужен Python 3.11 или 3.12 и токен тестового бота.

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

В `.env` укажите `BOT_TOKEN`. Файл не попадает в Git.

```bash
python -m app.main
```

Бот откажется стартовать без токена или если каталог не проходит проверку. База `data/app.sqlite3` и каталог `backups/` создаются при запуске и в Git не входят.

## Проверка

```bash
python -m pytest tests -q
python -m compileall app
```

## Что делает бот

1. Диагностика: бюджет на день, минуты готовки, кухня, продукты, исключения, полуфабрикаты, лимит активности, интервалы, место, инвентарь, интенсивность и часовой пояс.
2. Питание: завтрак, обед и ужин из каталога. Ограничения не ослабляются.
3. Тренировка и мини-планер: одна последовательность упражнений и короткие активности внутри свободных окон.
4. Один результат на сегодня или завтра. «Другой план» пропускает уже показанный вариант.

Цены считаются по порциям: `ceil(количество × цена упаковки / количество в упаковке)`. Это не стоимость покупки целых пачек.

## Резервная копия

Ежедневная копия появляется в `backups/ГГГГ-ММ-ДД.sqlite3` и хранится 3 дня. Восстановление: остановить бота, заменить `data/app.sqlite3` проверенной копией и запустить снова.

`/delete` удаляет пользователя, связанные строки и старые копии, затем пишет новую копию уже без этих данных. Сообщения в чате Telegram бот не стирает.

## Структура

```text
app/main.py            # long polling и worker
app/handlers.py        # команды и callback
app/dialogue.py        # переходы диагностики
app/schemas.py         # Profile, план, ошибки
app/services/          # питание, тренировка, расписание, оркестратор
app/repositories.py    # SQLite
app/validation.py      # каталог и постпроверка
app/formatting.py      # текст ответа
config/settings.json
config/messages.ru.json
catalog/               # продукты, рецепты, активности, тренировки
tests/
```
